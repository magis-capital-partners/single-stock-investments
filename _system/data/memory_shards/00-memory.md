# Memory

Approved beliefs for Marvin research. Proposals arrive as `[PROPOSED <LENS>]` bullets in
`_system/memory/daily/{date}.md`; `_system/scripts/build_memory_triage.py` collapses them
into `_system/reviews/pending/memory_triage.md`; a promotion pass moves approved items here
and records the decision so it never re-surfaces.

Reference library: `_system/reference/investment-wisdom/` (Munger, Pabrai, Stahl, Horizon
Kinetics, Mihaljevic/MOI). Model catalog: `_system/frameworks/mental_models.md`.
