# Daily lessons

Lessons for a session go in `daily/YYYY-MM-DD.md`. Append at most three `[PROPOSED]` lessons. Each lesson uses the blank form below. Do not invent a lesson to fill a date. Drew's local daily notes from 2026-07-23 through 2026-10-08 were copied in verbatim on 2026-10-12 (encoding repaired, nothing rewritten); older notes use looser forms and stay as written.

```text
## [PROPOSED]

- Evidence:
- Seen:
- Harmful:
- Scope:
- Review after:
```
