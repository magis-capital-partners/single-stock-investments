# Daily lessons

Lessons for a session go in `daily/YYYY-MM-DD.md`. Append at most three `[PROPOSED]` lessons. Each lesson uses the blank form below. Do not invent a lesson to fill a date. Drew's existing local daily notes are not in this repo until he copies them in.

```text
## [PROPOSED]

- Evidence:
- Seen:
- Harmful:
- Scope:
- Review after:
```
