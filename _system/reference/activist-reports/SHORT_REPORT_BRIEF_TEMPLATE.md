## Caveat checklist

- [ ] Reverse-split-adjusted prices, if a split falls after the report
- [ ] Delisted or OTC prints
- [ ] Prior-day squeeze (the pre-close is a spike, not a quiet price)
- [ ] Day-1 spike (an up day is a path fact, not a verdict)
- [ ] Release time unknown (for a 2025 note, Day 1 may be the next session)

## Outcomes

Delisting, a compliance deadline, or a regulator finding. If the check is empty, write "none found" and the date of the check.

## Universe

One company report is one row. A second report on the same name updates that row, the way a 13D amendment chain stays one campaign. A sector piece is not a row.
